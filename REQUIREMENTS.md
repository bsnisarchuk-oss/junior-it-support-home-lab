# Requirements

## Software Requirements

### Host Machine
- VirtualBox 7.x or VMware Workstation Pro
- Minimum 16GB RAM on host
- Minimum 100GB free disk space

### Guest VMs
- Ubuntu Server 22.04 LTS ISO
- Windows 10/11 ISO

## Skills Prerequisites

- Basic command line (Windows CMD / PowerShell, Linux Bash)
- Basic networking concepts (IP, DNS, DHCP)
- File system navigation

## Goals Checklist

- [ ] Ubuntu server deployed and accessible via SSH
- [ ] Samba shared folder configured and accessible from Windows
- [ ] Automated backup script running on schedule
- [ ] Windows workstations set up with standard software
- [ ] At least 4 incidents documented with resolution steps

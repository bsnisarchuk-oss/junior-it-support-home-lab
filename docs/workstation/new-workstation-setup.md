# New Workstation Setup

## Overview

Steps to set up a new Windows workstation in the lab environment.

## Steps

### 1. OS Installation
- [ ] Install Windows 10/11
- [ ] Apply all Windows Updates
- [ ] Set computer name (e.g., `WIN-WS-01`)

### 2. Network Configuration
- [ ] Set static IP or confirm DHCP assignment
- [ ] Test connectivity: `ping 192.168.1.1`
- [ ] Test DNS: `nslookup google.com`

### 3. User Account Setup
- [ ] Create local user account
- [ ] Set password policy
- [ ] Add to appropriate local groups

### 4. Software Installation
- See `software-installation-checklist.md`

### 5. Final Checks
- [ ] Remote Desktop enabled (if required)
- [ ] Firewall configured
- [ ] Antivirus installed and updated

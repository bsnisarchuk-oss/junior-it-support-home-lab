# Project Overview

## Goal

Simulate a small office IT environment to practice and document junior IT support tasks.

## Scope

- 1 Ubuntu Server (file server, backup server)
- 2–3 Windows 10/11 Workstations
- Basic network with router, switch, DHCP, DNS
- Shared folders via Samba
- Automated backups
- Incident response documentation

## Skills Practiced

- Windows workstation setup and user onboarding
- Linux server administration
- Network troubleshooting
- Incident documentation and resolution
- Scripting (PowerShell, Bash)
